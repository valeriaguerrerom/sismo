    Module map3d/domain

    Dominio geográfico y mapeo a coordenadas de escena 3D del "Mapa 3D".

    IMPORTANTE: aquí NO hay física. Solo se convierte (lat, lon, profundidad) a coordenadas de la escena Three.js para dibujar. Todo cálculo sísmico (distancias reales, tiempos, ondas) lo hace el backend.
