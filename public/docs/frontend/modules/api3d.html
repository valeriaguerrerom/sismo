    Module api3d

    Cliente HTTP tipado del backend del "Mapa 3D".

    Todo el cálculo (geometría, tiempos de viaje, síntesis FDM, MiniSEED) vive en el backend FastAPI. Este módulo solo hace las peticiones y tipa las respuestas. La URL base sale de VITE_API_URL; si no está, usa cadena vacía para aprovechar el proxy /api de Vite en desarrollo.
