    Escena 3D¶

    Mapeo autoritativo de coordenadas geográficas a la escena 3D del Mapa 3D (ejes del bloque, profundidad y proporciones).

    scene ¶

    Mapeo geo → coordenadas de escena 3D del "Mapa 3D" (backend autoritativo).

    REGLA TÉCNICA: todo cálculo numérico de la escena (conversión lat/lon/prof a posiciones de escena Three.js, tamaño del bloque, exageración vertical, escalas, niveles del eje de profundidad) se hace AQUÍ, en Python. El frontend solo renderiza las posiciones que este módulo entrega.

    El sistema de coordenadas de escena coincide con el que usaba el frontend (domain.ts) para no romper la escena existente: - X = longitud (oeste→este), centrado en 0, ancho BLOCK_WIDTH. - Z = latitud (norte hacia −Z), profundidad-plano BLOCK_DEPTH_XY. - Y = profundidad del subsuelo (hacia abajo negativo), alto BLOCK_HEIGHT.

    lon_to_x(lon: float) -> float ¶

    Convierte longitud (grados) a X de escena, centrado en 0.

    lat_to_z(lat: float) -> float ¶

    Convierte latitud (grados) a Z de escena (norte hacia −Z).

    depth_to_y(depth_km: float) -> float ¶

    Convierte profundidad (km) a Y de escena (negativo hacia abajo).

    domain_width_km() -> float ¶

    Ancho aproximado del dominio en km (para barras de escala).

    domain_height_km() -> float ¶

    Alto aproximado del dominio en km.

    km_to_scene_units(km: float) -> float ¶

    Convierte una distancia horizontal en km a unidades de escena X.

    scene_scale_bar(target_km: float = 50.0) -> dict ¶

    Longitud en unidades de escena de una barra de escala de target_km.
