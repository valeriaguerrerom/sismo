    Carga de MiniSEED¶

    Procesamiento de un archivo MiniSEED subido por un investigador: lectura en memoria con ObsPy, selección de una estación triaxial, filtrado opcional, normalización y diezmado. No persiste nada.

    mseed_upload ¶

    Carga de archivos MiniSEED por parte de investigadores.

    Endpoint

    POST /api/upload/mseed (multipart: file, station opcional, freqmin, freqmax)

    Lee el archivo con ObsPy, lista las estaciones disponibles, elige una estación con tres componentes (o la indicada), aplica detrend, un pasabanda opcional, normaliza a [-1, 1] y decima a un máximo de muestras. Devuelve un waveData con el mismo formato que usan el Explorador y el Simulador.

    No persiste nada en disco ni en base de datos: el archivo se procesa en memoria y el resultado vuelve al cliente.

    StationInfo ¶

    Bases: BaseModel

    Resumen de una estación encontrada dentro del archivo MiniSEED.

    Se usa para listar las estaciones disponibles y señalar cuál es apta para una visualización triaxial (tres componentes ortogonales).

    Attributes:

    Name Type Description
    station str

    Código de la estación (p. ej. CUFP).
    network str

    Código de la red sísmica a la que pertenece la estación.
    channels list[str]

    Canales presentes para la estación (p. ej. HHE, HHN, HHZ).
    sampling_rate float

    Frecuencia de muestreo en hercios (Hz).
    triaxial bool

    True si la estación tiene las tres componentes necesarias.

    WaveData ¶

    Bases: BaseModel

    Series temporales de las tres componentes de una forma de onda.

    Todas las listas comparten la misma longitud y el mismo eje de tiempo; las amplitudes vienen normalizadas al rango [-1, 1].

    Attributes:

    Name Type Description
    time list[float]

    Instantes de muestreo en segundos.
    north list[float]

    Amplitud de la componente Norte (N) en cada instante.
    east list[float]

    Amplitud de la componente Este (E) en cada instante.
    vertical list[float]

    Amplitud de la componente vertical (Z) en cada instante.

    MseedUploadResponse ¶

    Bases: BaseModel

    Resultado del procesamiento de un MiniSEED subido por un investigador.

    Reúne los metadatos de la estación elegida, la forma de onda normalizada lista para visualizar y, cuando es posible, una estimación de la distancia al foco a partir de la diferencia de llegada S−P. Nada de esto se persiste.

    Attributes:

    Name Type Description
    filename str

    Nombre del archivo original cargado.
    stations list[StationInfo]

    Estaciones encontradas en el archivo.
    station str

    Estación seleccionada para la visualización.
    network str

    Red de la estación seleccionada.
    channels dict[str, str]

    Canal usado por cada componente (claves N/E/Z).
    sensor_kind str

    Tipo de sensor usado (velocimetro o acelerometro).
    sampling_rate float

    Frecuencia de muestreo en hercios (Hz).
    starttime_utc str

    Instante inicial de la traza en formato ISO 8601 (UTC).
    duration float

    Duración de la señal en segundos.
    num_samples int

    Número de muestras por componente tras el procesamiento.
    normalization_factor float

    Factor por el que se dividió la señal para normalizarla al rango [-1, 1].
    filtro dict[str, float] | None

    Parámetros del filtro pasabanda aplicado, o None si no se filtró.
    waveData WaveData

    Series temporales de las tres componentes.
    orientation_confirmed bool

    True si las horizontales están orientadas a Norte/Este; False si vienen como 1/2 sin azimut (no se rotaron).
    orientation_note str | None

    Aviso cuando la orientación no está confirmada.
    horizontal_labels dict[str, str]

    Rótulos a mostrar para las dos horizontales.
    sp_seconds float | None

    Diferencia de tiempo S−P en segundos (None si no se detectó).
    distance_km_est float | None

    Distancia aproximada al foco en km, estimada por S−P.
    origin_class str

    Clasificación del origen de la señal.

    process_mseed_bytes(data: bytes, filename: str, station: str | None = None, freqmin: float | None = None, freqmax: float | None = None) -> MseedUploadResponse ¶

    Procesa un MiniSEED en memoria y devuelve el registro triaxial.

    Raises:

    Type Description
    ValueError

    si el archivo no es MiniSEED legible.
    HTTPException 404

    si no hay componente vertical.

    upload_mseed(request: Request, file: UploadFile = File(..., description='Archivo MiniSEED (.mseed/.msd/.seed)'), station: str | None = Form(default=None, description='Código de estación a extraer'), freqmin: float | None = Form(default=None, description='Pasabanda: frecuencia mínima (Hz)'), freqmax: float | None = Form(default=None, description='Pasabanda: frecuencia máxima (Hz)'), authorization: str | None = Header(default=None)) async ¶

    Devuelve el registro triaxial normalizado de una estación del archivo.

    Requiere sesión: la carga de MiniSEED es una función para investigadores autenticados, así que el token se verifica contra Supabase del lado del servidor (no basta con que la interfaz oculte el botón sin sesión).

    Registra cada intento de carga (éxito o fallo) en mseed_upload_logs para análisis de uso y debugging.

    Raises:

    Type Description
    HTTPException 401

    sin sesión o token inválido.
    HTTPException 400

    archivo vacío, demasiado grande o ilegible.
    HTTPException 404

    estación inexistente o sin componente vertical.
    HTTPException 422

    estación fuera del proyecto o falta componente.
    HTTPException 429

    si se supera el límite de cargas por IP.

    download_example_mseed() ¶

    Sirve el archivo MiniSEED de ejemplo (registro real corto de CUM).

    Es un registro tectónico de la estación CUM (Cumbal, Nariño) con velocímetro y acelerómetro, para probar la carga. Se sirve como descarga desde el propio backend (no depende de Supabase Storage).

    Raises:

    Type Description
    HTTPException 404

    si el archivo no está en la imagen.

    download_example_mseed_by_kind(kind: str) ¶

    Sirve un MiniSEED de ejemplo según el tipo de fuente.

    Parameters:

    Name Type Description Default
    kind str

    'tectonico' (estación CUM, red del SGC) o 'volcanico' (estación CUFP del Volcán Galeras, OVSP). Ambos son registros reales cortos y triaxiales para probar la carga.

    		 required

    Raises:

    Type Description
    HTTPException 404

    tipo desconocido o archivo no disponible.
